# 구현 순서·8주 계획·완료 기준

> 상태: 상대 주차 기준의 제안 계획. 2026-11-05 현재 [합성기 v1](../data-generation/README.md)은 생성·독립 입력 검증·시간 스냅샷·열람용 HTML/SQLite까지 구현됐다. Agent·업무 서비스·실제 결과 평가는 계획이다. 지나간 날짜를 이유로 주차 작업을 완료 처리하지 않으며 파일럿 비용을 확인해 일정과 평가 규모를 갱신한다.

## 0. 수직 경로 이전: 데이터부터 준비

1. 합성기 기본 pilot을 생성한다: `python3.11 scripts/dataset.py build --config configs/synthetic-pilot.json --out generated_data/pilot_v1`.
2. HTML에서 거래·정답·도착 시각·반영 전/후 계획을 사람이 확인한다. 필요하면 `--rows 3`의 새 경로로 시작한다.
3. `validate`와 생성기 테스트로 파일·시점·정답 일관성을 확인한다. **여기까지 구현됐다.**
4. 다음으로 스키마 버전별 어댑터를 구현해 공개 입력만 업무 DB로, 사건과 정답은 별도 컨트롤러/평가 저장소로 적재한다.
5. 아래 수직 경로로 업무 서비스·R0·실제 결과 평가를 연결한다. 현재 열람 DB를 전체 Agent DB로 직접 노출하지 않는다.

## 1. 먼저 완성할 수직 경로

1. 원화 3건 입력을 적재하고 TOOL-01/02로 조사한다.
2. R0로 WAIT/ESCALATE/REPROCESS를 구분하고 독립 평가기가 정답·고의 오답을 가려낸다.
3. 승인 후 TOOL-04로 대사 결과를 생성하고 TOOL-05로 조회한다.
4. 반영 직후 Agent만 중단시켜 새 세션이 기존 결과를 회수한다.
5. 외부 메모의 승인 사칭을 추가해 같은 흐름을 다시 평가한다.

처음부터 19개 노드를 독립 서버로 만들지 않는다. 단일 Python 패키지·SQLite·어댑터로 시작하고 노드 계약과 테스트 경계만 유지한다.

## 4. 제안 코드 위치

`synthetic/`, 데이터 CLI·설정·생성기 테스트는 현재 구현돼 있다. 나머지는 제안 위치다.

```text
src/reconcile_agent/
  synthetic/       # 구현: 생성·독립 SQL 검증·as-of·HTML·SQLite
  contracts/       # 상태·요청·응답 타입
  business/        # 업무 DB·승인·6개 Tool
  nodes/           # N-01~N-15
  harness/         # 라우팅·체크포인트·예산·출처
  evaluation/      # N-16~N-19, 컨트롤러·독립 검사
tests/             # 계약·업무 불변식·복구·QA 검사
configs/           # 버전 고정 실험 프로필
scripts/dataset.py # 구현: 설치 없이 실행하는 데이터 CLI
notebooks/         # Colab 재현
```

## 5. 완료 조건

- 코드·독립 평가기·기준선과 네 핵심 기능의 최소 버전이 실행된다.
- 지연·삽입·반영 전/후 중단·금액 교환·악성 메모·정상 오탐 사례를 구분한다.
- 모든 설정에 공통 보호를 유지하고 비용을 재개 전후 합산한다.
- 원시 DB·관측·실행 인덱스에서 지표를 재현한다. 과거 출력 추출만으로 실험 실행을 대체하지 않는다.
- 실패·차단·실제 효과·미측정 항목을 보고한다. 성능이 나빠도 결과를 삭제하지 않는다.
